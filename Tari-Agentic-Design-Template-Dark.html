Philosophy: Minimal and sleek. Neutral surfaces, restrained color. Every element earns its place. Fonts: DrukWideFont (display, 40px+, uppercase, weight 700-800) · Poppins (all UI, weight 400-600) · JetBrains Mono (code) Dark surfaces: page #0c0718 · card #130f22 · raised #1e1836 · border #2e2850 Light surfaces: page #fbf7ef · card #ffffff · raised #f6f4fb · border #d4cfea Accent: #c9eb00 lime (sparingly) · CTA gradient: linear-gradient(90deg, #5a63d3, #3342ff) Buttons: Primary = gradient, weight 600 · Secondary = neutral surface card, border-default, weight 500 · Ghost = transparent, text-secondary · Accent = lime bg, dark text Cards: neutral surface-1 bg, border-subtle, 16px radius — never tinted fills Inputs: underline-only, lime scaleX sweep on focus Alerts/Toasts: neutral card bg, semantic color on icon only — never tinted backgrounds Checkmark on lime: always #0c0718 — never white on lime

Checkboxes
Spring-animated selection controls. The check pops in with a brief overshoot on selection, using the same spring timing as all other interactive primitives.
Radio Buttons
Mutually exclusive option selectors. The active dot scales in with a spring bounce on selection, maintaining visual coherence with checkboxes and toggles.
Toggles
Binary on/off controls. The thumb slides with a spring bounce when toggled. Use for settings and preferences — not as a substitute for checkboxes in forms.
